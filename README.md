# Oracle Fusion HCM Efforts Estimator

A web-based effort estimation tool for Oracle Fusion HCM implementations.

## Features

- Create and manage Change Requests (CRs)
- Effort estimation based on configuration complexity
- PDF export support
- Charts and analytics
- Seeded configuration templates

## Deployment

This project is deployed on [Vercel](https://vercel.com) as a static site.

### Deploy your own

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Fork this repository
2. Import it in Vercel
3. Deploy — no build step required

## Local Development

Just open `index.html` in your browser — no build tools needed.
